# 引用検証ルール

## エラー

- 本文引用に対応する参考文献がない。
- 参考文献番号が別の文献を指す。
- PMIDまたはDOIが、記載されたタイトル・著者・雑誌と一致しない。
- 本文の主張と引用先の対象・介入・結論が明らかに異なる。

## 警告

- 参考文献リストにあるが本文から参照されない。
- 年、巻、号、ページ、著者名の一部が一致しない。
- 同一文献が重複している。
- 出版前版と最終版が混在している可能性がある。

## 情報

- 書式の不統一。
- DOIやPMIDの追記候補。
- 雑誌略称と正式名の差。

## 照合

1. PMIDを最優先のキーとしてPubMedページを開く。
2. PMIDがなければDOI、タイトル、第一著者、年で検索する。
3. タイトル、著者、雑誌、年、DOIを個別に比較する。
4. 本文の主張が引用で支持されるかは、少なくとも抄録で確認する。
5. 抄録だけでは判断できない場合は「本文確認が必要」とする。

## 修正

- 識別子の1桁違いでも、正しいPMIDを推測だけで確定しない。
- 自動修正はユーザーが承認した項目だけに限定する。
- 修正後に本文引用、参考文献リスト、PubMed書誌を再照合する。
