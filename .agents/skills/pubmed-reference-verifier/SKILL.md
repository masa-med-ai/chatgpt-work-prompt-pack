# PubMed Reference Verifier

詳細な判定規則は、検証開始前に[references/verification-rules.md](references/verification-rules.md)を読む。

## 1. モードを決める

- **check**: 原稿内の引用と参考文献リストだけを相互照合する。
- **verify**: checkに加え、PubMedで書誌を確認する。既定。
- **fix**: verify後、修正案を提示し、ユーザー承認後に対象ファイルを変更する。

原稿が複数ある場合は対象を確認する。原本を上書きせず、fixは別名保存を既定にする。

## 2. 原稿内を照合する

1. 本文中の番号引用、著者年引用、PMID、DOIを抽出する。
2. 参考文献リストの各項目を構造化する。
3. 本文にあるがリストにない引用、本文から参照されない項目、重複、番号ずれを検出する。

## 3. PubMedで検証する

利用可能なPubMed Plugin／MCPを優先し、なければWeb searchで`pubmed.ncbi.nlm.nih.gov`を使う。

各項目についてPMID、タイトル、第一著者、雑誌、年、DOIを照合する。PMIDが別分野の論文を指す場合は重大な不一致として扱う。検索で確認できない項目を正しいと推測しない。

## 4. 報告する

次の列で結果を示す。

| ID | 場所 | 種別 | 重大度 | 現在値 | 確認結果 | 修正案 | 根拠URL |
|---|---|---|---|---|---|---|---|

重大度はError、Warning、Infoとする。検証できなかった項目はUnverifiedとする。

## 5. 修正する

fixでも自動適用しない。修正対象、変更前、変更後、根拠を提示して承認を得る。承認された項目だけ変更し、差分を示して再検証する。

確認できない引用の削除、別論文への置換、本文の主張変更は、ユーザーの明示的な判断なしに行わない。
