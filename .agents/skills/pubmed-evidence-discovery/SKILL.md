# PubMed Evidence Discovery

## 原則

- 確認できた原文だけを根拠にする。記憶や類推で数値を補わない。
- 検索式、取得件数、採否、抽出箇所を追跡できる形で残す。
- 抄録にない値は`NR`とする。計算値は「算出」と明記し、正式なメタ解析には原著確認が必要と伝える。
- Primary outcome、secondary outcome、登録数、解析数、介入群、対照群を区別する。
- 多数の抄録を一度に取得して出力が切れた場合、その結果を使わない。小さな単位で再取得する。

## Formal reviewとの境界

このSkillだけで「系統的レビュー完了」「メタ解析完了」と主張しない。正式なsystematic review／meta-analysisには、少なくとも事前プロトコル、複数データベース、再現可能な検索、重複除去、2名以上の独立スクリーニング／抽出、全文確認、risk of bias評価、PRISMAフロー、解析計画が必要である。

これらが揃っていない依頼は「PubMedによる予備的エビデンス探索・抄録ベース比較表」と明示する。正式レビューを求められた場合は不足要件を示し、予備探索として進めてよいか確認する。

## 1. 問いと検索式

1. PICO、期間、研究デザイン、主要評価項目を確認する。
2. MeSHと自由語を組み合わせた検索式を作る。
3. 可能なら本検索前に件数を確認する。
4. 0件または件数が多い場合は科学的な範囲を再検討する。処理量だけを理由に対象期間やデザインを勝手に狭めない。
5. 検索式、実行日、件数を保存する。

利用可能な情報源は次の順で選ぶ。

1. 接続済みPubMed Plugin／MCP
2. PubMed用検索ツール
3. Web searchで`pubmed.ncbi.nlm.nih.gov`

使えない接続を装わない。

## 2. スクリーニング

タイトルと抄録を確認し、適格・除外・保留に分類する。除外理由を1論文1つ以上記録する。重複をPMIDまたはDOIで除く。

## 3. 個別抽出

各論文から次を抽出する。

| 項目 | 規則 |
|---|---|
| PMID、第一著者、雑誌、年 | PubMed書誌と照合する |
| Design | RCT、parallel、tandemなどを原文どおり記録 |
| N analyzed | 登録数ではなく解析数を優先 |
| Intervention／Control | 群の向きを原文で確認 |
| Primary outcome | primaryと明示された項目 |
| Group results | 単位と分母を含める |
| Effect／CI／P | 原文記載値を優先 |
| Source | Abstract、本文、表、図の別 |

取得内容が途中で切れた場合、その論文の抽出を破棄して再取得する。

## 4. 検証

出力前に各行を確認する。

- Nは解析対象数か。
- Primary outcomeは原文でprimaryと明示されているか。
- 介入群と対照群が逆でないか。
- P値、CI、有意性判定が整合するか。
- 原文にない値を補っていないか。
- 同一著者の別研究を混同していないか。

学会・論文など高stakesの成果物では、独立した2名によるスクリーニングと抽出、risk of bias評価、全文照合を行う。このSkillの単独抽出を最終データとして使わない。

## 5. 出力

比較表には第一著者、雑誌、年、N、主要結果、PMIDリンク、情報源を含める。

Excelではヘッダー固定、フィルター、折返し、適切な列幅、PMIDリンクを設定する。スライドでは1枚のメッセージを絞り、確認済み数値だけを記載する。生成後はファイルを開いて表示を検証する。

forest plotや統合推定値は、比較可能な効果指標と分散が原著で確認され、解析計画がある場合に限る。抄録値だけの教育デモでは統合推定値を作らない。

最後に、検索式、データベース、取得数、採用数、除外数、未確認事項、正式レビュー要件の不足、原著確認が必要な箇所を報告する。
