# images — ワークショップ図版

## 現行パックで使う図版

Level 3と4では、個人のアカウント表示、ライブラリ構成、インストール済みAdd-inなどが写るUIスクリーンショットを配布しない。Wordの完成イメージは匿名化済みのサンプルPDFを使い、EndNoteは参加者自身の画面で操作を確認する。

## 追加時のルール

- UIスクリーンショットには確認日を添える。
- 患者情報、メールアドレス、認証情報、アカウント名、個人ライブラリ、ローカルパス、インストール済みAdd-inを写さない。
- 機能名はOpenAI公式ドキュメントと実機表示で確認する。
- Markdownからは相対パス `images/ファイル名` で参照する。
