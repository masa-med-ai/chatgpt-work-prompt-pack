# ChatGPT Work Prompt Pack

医療従事者・研究者が、ChatGPT Workの代表機能を安全なハンズオンで理解するためのPrompt Packである。

## 始め方

1. このリポジトリをダウンロードまたはcloneする。
2. ChatGPTデスクトップアプリで、このフォルダをローカルProjectのprimary folderとして開く。
3. ChatGPTを選び、Workを有効にする。
4. 次の一文を送る。

```text
00_START_ここから.md を読んで、ワークショップを始めて。
```

利用できる機能はプラン、組織設定、OS、インストール済みPluginで異なる。最初の環境確認が、実行できるLevelと代替ルートを案内する。

## 体験できること

- Work locallyとCloudの使い分け
- Projects、Personalization、Memory、`AGENTS.md`
- Word、PDF、Excel、PowerPointの作成と表示検証
- Web searchとPubMed引用検証
- SkillsとPlugins
- Sites、Browser、Computer Use
- GmailからGoogle Calendarへの安全な予定登録
- GoalとScheduled tasks
- Image inputとローカルAIアプリ

## 安全

- 実患者情報・患者画像・認証情報を使わない。
- 個人のメールアドレス、アカウント名、PC固有の絶対パス、ローカル設定が写ったスクリーンショットをリポジトリへ保存しない。
- メール送信、予定変更、公開、共有設定変更、購入、削除は承認前に実行しない。
- 医学論文の数値と引用は原文・PMIDで確認する。
- 旧Claude版の実行形式・図版は現行配布から除外している。
